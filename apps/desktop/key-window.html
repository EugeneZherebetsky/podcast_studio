Provider keys

Keys are stored encrypted for your Windows account and are not used until you switch them on here. When activation is on, each ticked key is given to the local Podcast Studio server process the next time the app starts, so that the cloud speech provider you choose in Settings can be called. Activation does not choose a provider and does not change your saved Settings. This window can never show a stored key.

Changes apply only after you quit and reopen Podcast Studio. Saving, clearing or ticking a key never restarts or interrupts the running server. Finish any jobs before you quit.

Limitation: other programs running under your Windows account can read this app's memory and the server process environment, so they can obtain an active key. Keys are sent only to the provider's own HTTPS address. Provider charges are billed by the provider and are not counted in the monthly budget.
